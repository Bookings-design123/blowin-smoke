# Pressure & Proof Static Visual Prototypes

**Status:** Synthetic prototype package; non-production

**Implementation authorization:** Not granted

This isolated package visually tests the governing Pressure & Proof direction across the thirteen representative page and layer compositions required by `docs/system/06-high-fidelity-page-design-specifications.md`. It is research/design evidence, not an application, component library, catalog, eligibility engine, compatibility service, cart, or deployment artifact.

## Package contents

- `index.html` — local prototype directory.
- `prototype.css` — package-only provisional visual grammar.
- `pages/` — thirteen standalone semantic HTML compositions.
- `assets/` — notes for prototype-local placeholder treatment; no fabricated production brand or product assets.
- `screenshots/wide/` — inspected 1440 CSS-pixel exports.
- `screenshots/narrow/` — inspected 390 CSS-pixel exports.

## Fixture discipline

Every identity, price, variant, batch, proof record, relationship, dimension, source, availability, eligibility result, cart condition, and media object in this package is visibly synthetic. Bracketed values and placeholder names deliberately avoid a plausible live-catalog appearance. No competitor copy, imagery, color system, or trade dress is present.

The actual `docs/brand/assets/blowin-smoke-logo.png` appears only on the Home page at a spacious editorial scale. Its opaque padded canvas is preserved. The persistent header uses live text because a compact production mark has not been supplied and must not be fabricated.

## Static interaction notation

Hover, focus, selected, blocked, loading, error, changed, drawer, and modal-like layer states are labeled visual specimens. They do not imply event handling, persistence, validation, live data, focus management, network behavior, checkout readiness, or any other functional service. No JavaScript is required for the representative exports.

## Typeface test

The CSS requests `Archivo` first, followed by documented system fallbacks: `Arial Narrow`, `Arial`, and `sans-serif`. No font file is bundled or downloaded. The evaluation records which face the export environment actually rendered.

## Local review

Open `index.html` through any static local server, then inspect every representative page at the exported wide and narrow test canvases. These test canvases are not production breakpoints. The committed PNGs are visual evidence from the review pass and do not make an accessibility-conformance claim.

## Boundary

Nothing here should be imported into `app/`, `components/`, `lib/`, `public/`, a runtime bundle, or a deployment. Prototype CSS values remain provisional until the evaluation in `docs/system/07-static-visual-prototype-evaluation.md` decides whether to retain, adjust, reject, or leave them open for the next specification.
