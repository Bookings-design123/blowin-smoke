# Prototype asset boundary

No production product, proof, compatibility, measurement, maker, or editorial asset is stored here.

Product/media areas use package-only CSS geometry and explicit labels such as “synthetic identity media” or “media unavailable.” Those shapes are not logos, packaging, product depictions, or proposed illustration assets. They exist to test ratio, hierarchy, missing-media resilience, and the relationship between imagery and structured truth.

The only existing brand asset used by the package is referenced in place from `docs/brand/assets/blowin-smoke-logo.png` on the spacious Home composition. It is not copied, cropped, recolored, masked, or processed here.
