# Blowin' Smoke Documentation

This directory contains the complete knowledge base for the Blowin' Smoke project.

The purpose of this folder is to separate business strategy, research, architecture, and implementation from the application code.

The website should never evolve independently of these documents.

---

## Documentation Structure

constitution/
Brand philosophy, design principles, UX philosophy, commerce philosophy.

research/
Firecrawl research, inspiration analysis, screenshots, summaries.

architecture/
Site maps, navigation, product taxonomy, database schema.

implementation/
Codex prompts, build plans, implementation notes.

assets/
Brand assets, logos, photography, inspiration images.
